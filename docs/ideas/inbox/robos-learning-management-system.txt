RobOS Learning Management System - as "eLearning Courses" are created as SDLC artifacts etc... it would be good to have a elearning coures player that tracks the data on the store allowing common LMS features:
- Declarative course schema for SDLC courses (lessons, modules, quizzes, labs) generated by agents or developers
- Interactive course player with video walkthroughs, code diffs, architecture diagrams, and knowledge checks
- Progress tracking, bookmarks, quiz grading, and completion tracking on the RobOS GitOps data store
- Integration with People Directory & Group Manager for team learning paths and compliance tracking
- Live practice labs integrating with RobOS IDE and terminal sandboxes
