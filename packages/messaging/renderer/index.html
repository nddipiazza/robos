How RobOS uses these

Each network can be reached in up to two ways.

Web sign-in

The network's own website, signed in here with your personal account. Every network gets its own private browser storage, so Messenger never sees your Instagram or Snapchat sign-in. RobOS shows the unread count and passes on the network's notifications, but cannot read or send these chats itself.

Connector

A link RobOS can use itself. Conversations show in the Inbox, and RobOS agents and scripts can read and send with the robos-messaging command:

robos-messaging conversations
robos-messaging read signal:+15551234567
robos-messaging send --network signal --to +15551234567 "On my way"
