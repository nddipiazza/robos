    <div class="panel-g">
      <p class="eyebrow">How a party runs</p>
      <h2 class="h2">The AI writes the show while you gather</h2>
      <p class="sec-p">Agent replies take seconds, so the AI host never makes the room wait: it writes in the background while guests are still arriving. A guest finishes the survey and gets a personal welcome on the TV. The party host describes the house and the host gives a quick house tour. Once everyone is in, the writers' room drafts the whole show in parallel. Standings recaps and finale awards are written while the previous round is still on screen. If a call is slow or fails, the host uses stock material and the party keeps moving.</p>
      <div class="facts">
        <div><b>Required</b><span>an AI agent and a RobOS TV</span></div>
        <div><b>Phones</b><span>as controllers</span></div>
        <div><b>In the background</b><span>every AI call</span></div>
        <div><b>Apache-2.0</b><span>open source</span></div>

npm install
npx electron . --no-sandbox</code></pre>

  score(round, answers, ctx) { /* { correct, awards, reveal } */ },
});</code></pre>
