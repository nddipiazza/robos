# Story 14-05: People Directory

**Epic:** [Developer Experience & Testing](epic.md)
**Status:** Not started
**Points:** 3

## Description

Simple team directory app. Shows team members with: name, role, GitHub username, Slack handle, timezone. Search and filter. Click to view profile with recent activity (PRs, tasks). Data sourced from EKGraph people nodes or team config in distributed store. Useful for finding who owns a service or who to ask about a codebase area.
