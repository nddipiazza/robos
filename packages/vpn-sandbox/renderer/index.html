Sandbox Launch Executable via OpenVPN

5-Layer Zero-Leak Enforced

Enter any executable name (e.g. firefox, curl, transmission-gtk) or path. RobOS spawns it inside an isolated Linux network namespace (ip netns) locked with dual-layer iptables + ip6tables rules so it is impossible for your normal IP to ever carry traffic from that app.

Zero-Host-IP Leak Guarantee (Enforced Before Exec):
  • No Host Interface Access: Physical interface (eth0) does not exist inside namespace robos_vpn_*.
  • In-Namespace iptables -P OUTPUT DROP: App UID is blocked on veth (-m owner --uid-owner 0 only) and can ONLY transmit over tun+.
  • Host Kernel FORWARD Lock: Host drops all packets from the sandbox unless destined to the exact OpenVPN server IP & port.
  • IPv6 & DNS Locked: ip6tables -P OUTPUT DROP + namespace-bound /etc/netns/<ns>/resolv.conf over tun0.
