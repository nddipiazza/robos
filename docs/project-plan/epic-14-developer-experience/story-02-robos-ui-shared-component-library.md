# Story 14-02: robos-ui Shared Component Library

**Epic:** [Developer Experience & Testing](epic.md)
**Status:** Not started
**Points:** 8

## Description

Shared dark-theme Web Components library used by all RobOS Electron apps. Components: buttons, inputs, dropdowns, modals, tabs, cards, tables, toasts, progress bars, code blocks. All styled with RobOS design tokens (--bg-primary, --accent, etc.). Vanilla JS Web Components (no framework). Published as a local package, imported in renderer HTML.
