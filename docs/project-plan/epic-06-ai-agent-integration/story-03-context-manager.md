# Story 06-03: Context Manager

**Epic:** [AI Agent Integration](epic.md)
**Status:** Not started
**Points:** 5

## Description

Electron app to curate AI context sources per task or project. Add context from: files, folders, URLs, repos, task server tickets, EKGraph nodes. Create named context bundles. Auto-attach relevant context when an agent starts a task. Show total context size and token estimate. Voice-to-text notes added to context.

## Acceptance Criteria

- [ ] Tested end-to-end with buildbarn-forms example task
- [ ] Agent actions visible in real-time in the UI
- [ ] Task workflow stage advances correctly
