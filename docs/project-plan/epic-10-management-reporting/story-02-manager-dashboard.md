# Story 10-02: Manager Dashboard

**Epic:** [Management & Reporting](epic.md)
**Status:** Not started
**Points:** 5

## Description

Team-level metrics: tasks in progress by stage, per-developer velocity (stories/sprint), cycle time (time from start to merge), deployment frequency, bug escape rate. Drill down by: developer, project, sprint, release. Configurable metric cards — drag to rearrange, add/remove. Time range selector.

## Acceptance Criteria

- [ ] Data sourced from task server and CI systems (not hardcoded)
- [ ] Updates in real-time or near-real-time
- [ ] Dark theme consistent with RobOS design system
