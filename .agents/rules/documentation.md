# Documentation Diagrams Rule

- **AI Generated Images**: When creating RobOS documentation diagrams, always generate and include Gemini 3.8 AI-generated images/illustrations alongside Mermaid syntax.
- **Style Guidelines**: Diagrams must be very professional, developer-friendly, clean, functional, and extremely easy to read. Avoid chaotic AI "wow bling" or cluttered decorative fluff; focus on crisp, structured technical architecture, clear flow schematics, and legible labels.
