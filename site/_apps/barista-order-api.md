Specialty coffee roastery order queue, origin bean catalog, and barista drink fulfillment microservice.

## Source and integration

The component lives in [`packages/barista-order-api`](https://github.com/nddipiazza/robos/tree/main/packages/barista-order-api).

Its entry point is [`server.js`](https://github.com/nddipiazza/robos/tree/main/packages/barista-order-api/server.js).

See the [package README](https://github.com/nddipiazza/robos/tree/main/packages/barista-order-api/README.md) for setup and usage.

## Run from source

From `packages/barista-order-api`, install the dependencies and run:

```bash
npm install
npm start
```

## Validation

Run `npm test` from `packages/barista-order-api`. The command is defined in the [package manifest](https://github.com/nddipiazza/robos/tree/main/packages/barista-order-api/package.json).
