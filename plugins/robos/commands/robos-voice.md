# /robos-voice

Interact with the RobOS Voice subsystem to speak out loud, query voices, monitor the continuous background stream, or talk to the Desktop Assistant.

## Usage

```bash
# Speak text out loud in natural human voice
/robos-voice speak "Hello Lead Architect"

# Ask RobOS Desktop Assistant
/robos-voice assistant "What is our git branch?"

# Enumerate natural voice models
/robos-voice voices

# Control background stream
/robos-voice background start
```
