# Story 05-02: Git Projects Repo Manager

**Epic:** [Workspace Management](epic.md)
**Status:** Not started
**Points:** 5

## Description

Electron app for managing local git repositories. Clone from URL, pull/fetch, view branches, switch branches. AI generates dev-setup instructions by analyzing repo structure (package.json, Makefile, docker-compose, etc.). Monaco editor for quick file edits. Terminal runner for commands. Open-in-IDE button.

## Acceptance Criteria

- [ ] Tested with buildbarn-forms example project
- [ ] Works with both JetBrains IDEs and VS Code
- [ ] Errors handled gracefully with user-visible messages
