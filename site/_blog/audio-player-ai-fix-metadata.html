Reusable RobOS UI components and the fix-media-metadata skill. Rather than inventing custom prompt controls, AI Fix Metadata embeds the standard <robos-agent-selector> and <robos-ai-textarea> (packages/audio-player/src/AiFixMetadata.jsx) with /skills command browsing and @mention file typeahead wired to packages/robos-lib/skill-catalog.js. The textarea opens pre-populated with @skill(robos:fix-media-metadata) (plugins/robos/skills/fix-media-metadata/SKILL.md), giving your chosen coding agent (AGY, Claude Code, Codex, Gemini CLI, or GitHub Copilot) full domain instructions on container tag layouts, scene/ripper filename noise removal, open-data cross-referencing, and cover art selection.

100% open-source, legal media probing and artwork pipeline. For every track in the selected scope (selected rows, active folder, tracks missing metadata/art, or a library batch), packages/audio-player/lib/ai-metadata.js runs a multi-stage open-source pipeline: it parses container tags with MIT-licensed music-metadata, probes stream/container headers and attached pictures with ffprobe, inspects sibling .cue, .lrc, and .nfo sidecars, and queries the CC0 MusicBrainz WS/2 API and LRCLIB. For tracks missing cover art, it extracts embedded APIC / METADATA_BLOCK_PICTURE / covr streams or representative video frames via ffmpeg, checks folder images (cover.jpg, folder.png), downloads official sleeves from the Cover Art Archive, or synthesizes an open-source FFmpeg waveform / SVG album sleeve. Every proposed change is presented as an interactive before→after diff card so you can review and selectively apply updates to the library index, playlists, and (optionally) directly into local media files via lossless ffmpeg -c copy stream muxing.
