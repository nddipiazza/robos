`packages/barista-order-api` is the reference Node.js HTTP microservice generated by the [New App Wizard](/new-app-wizard/) (`node-microservice` archetype). It models a specialty coffee roastery order queue and bean catalog with an explicit OpenAPI specification (`openapi.yaml`), Backstage entity descriptor (`catalog-info.yaml`), `Dockerfile`, and Knowledge Graph service node.

## Endpoints & local verification

- **`GET /api/health`**: Liveness and readiness JSON health probe.
- **`GET /api/items`**: Returns the specialty coffee menu and active fulfillment items defined by [`openapi.yaml`](https://github.com/nddipiazza/robos/blob/main/packages/barista-order-api/openapi.yaml).

```bash
cd packages/barista-order-api
npm test
npm start
```

Inspect or exercise its OpenAPI contract inside [REST API Client](/rest-client/) and [Contract Studio](/contract-studio/). Source: [`packages/barista-order-api`](https://github.com/nddipiazza/robos/tree/main/packages/barista-order-api).
