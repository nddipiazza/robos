# Dev Central — AI Agent Review-Based Development Hub

**Status:** Not started
**Priority:** High
**Dependencies:** AI Agent Integration, Task Management, Workspace Management, RobOS Desktop Agents, Contract-Driven Project Graph

Rebrands and re-architects RobOS Dev Central (`packages/dev-central`) from a traditional developer dashboard into the central command center for **AI Agent Review-Based Development** (inspired by the Antigravity IDE workflow). Empowers lead developers to drive software delivery by managing organizations and project graphs, dispatching strategic agent prompts with Planning Mode, reviewing AI Implementation Plans and actively probing assumptions before execution, monitoring real-time agent swarms, verifying Proof-of-Work walkthroughs, and escalating blockers.
