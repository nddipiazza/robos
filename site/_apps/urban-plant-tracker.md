`packages/urban-plant-tracker` is a full-stack Next.js 15 (App Router) and React 19 web application generated from the [New App Wizard](/new-app-wizard/) `nextjs-vercel-web` launch kit (distilled from [Get ’Em Gigs](/getemgigs/)). It tracks indoor plant watering schedules, room sunlight logs, and botanical care guides.

## Built-in stack & production guards

- **Zero-setup local Postgres**: Uses Neon serverless Postgres in production (`DATABASE_URL`) and embedded **PGlite** locally and in unit tests (`src/lib/schema.js`) so `npm run dev` and `npm test` run with no external database container.
- **Session & abuse security**: Email + bcrypt password authentication, SHA-256 hashed opaque session cookies (`HttpOnly`, `SameSite`), Postgres-backed rate limits, CSRF origin enforcement, strict CSP/HSTS headers, and optional reCAPTCHA v3.
- **Multi-actor E2E video evidence**: Playwright + Cucumber scenarios (`tests/e2e/`) record synchronized mobile viewports and compile proof reels via `npm run evidence`.

```bash
cd packages/urban-plant-tracker
npm install
npm test
npm run dev
```
