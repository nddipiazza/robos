KeePassXC (.kdbx) vault & YubiKey unlock

RobOS Pass Manager stores your credentials, API tokens, database URLs, and notes inside a single portable KeePassXC .kdbx 4.1 archive (AES-256 / Argon2id) and binds it to your physical YubiKey / FIDO2 Security Key using the CTAP2.1 hmac-secret extension—so you can unlock your entire keystore with a single finger press on the key's gold contact.

  • ArchitectureKDBX 4.1 archive, FIDO2 hmac-secret & /dev/shm session
  • 3 Hardware Modes1-Touch OR Password, Touch-Only & 2FA Composite
  • Entry Studio & GeneratorGroups, structured fields & entropy estimation
  • KDBX Cipher & Bindingkeepassxc-cli db-info & FIDO2 key enrollment
  • Hardware Keys GuardCross-app unlock & USB unplug auto-lock
  • CLI & API Referencekdbx-vault.js, files & debug port :19113

Architecture

Instead of scattering folder trees and filenames in plain view on disk (as traditional pass stores do with ~/.password-store/**/*.gpg), RobOS Pass Manager uses the standard single-file KeePassXC KDBX 4.1 container format backed by keepassxc-cli and the shared engine in packages/robos-lib/kdbx-vault.js. Group names, entry titles, usernames, passwords, URLs, and notes are all encrypted inside one .kdbx file (`~/.config/robos/vault/robos-passwords.kdbx` by default).

1. Three Hardware Key Protection Modes

When creating a new .kdbx archive (New…) or binding a YubiKey to an existing database (⚙), RobOS supports three cryptographic binding modes:

Protection ModeHow Unlock WorksBest For
1-Touch Physical Key OR Master Password (Recommended)Touch your YubiKey for instant 1-touch unlock over FIDO2 hmac-secret, or type your Master Password if your key is not with youDaily workstation convenience with full password recovery backup
Physical YubiKey Touch ONLYZero master password—the .kdbx archive is encrypted directly by the 256-bit hardware hmac-secret output of your YubiKeyMaximum hardware isolation where no memorizable password exists
2FA Composite Key (Password + YubiKey Touch)Derives the AES-256-GCM wrapping key via PBKDF2-HMAC-SHA256(masterPassword, yubikeyHmacSecret, 100000)—requiring both knowledge and physical possessionHigh-security production or infrastructure vaults

2. Entry Studio & Password Generator

Once unlocked, RobOS Pass Manager presents a collapsible group/entry tree on the left and a structured credential inspector on the right:

  • Auto-Clearing Clipboard: Clicking 👤 Copy User or 📋 Copy Password copies the field to the system clipboard and automatically wipes it after 30 seconds if unchanged.
  • Inline KeePassXC Password Generator: Click + in the top toolbar to add a new entry or ✏️ Edit to update an existing one. The inline generator invokes keepassxc-cli generate and keepassxc-cli estimate to produce high-entropy secrets of any length (8–128 chars).
