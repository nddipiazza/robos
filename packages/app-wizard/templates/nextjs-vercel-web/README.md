## What you get out of the box

| Area | Included |
|:---|:---|
| **Stack** | Next.js 15 App Router, React 19, plain mobile-first CSS (bottom tab bar, safe areas, 16px inputs) |
| **Database** | Neon serverless Postgres in production (`DATABASE_URL`); embedded **PGlite** locally and in tests — zero setup. Idempotent schema in `src/lib/schema.js` |
| **Auth** | Email + password (bcrypt), opaque server-side sessions (SHA-256 hashed tokens), HttpOnly/SameSite cookies, account deletion |
| **Abuse controls** | Postgres-backed rate limits, honeypot + minimum form-fill time, disposable-email block, password rules, same-origin (CSRF) checks, 20 KB body cap, audit log |
| **CAPTCHA** | reCAPTCHA v3 wired in but **disabled** until you set `RECAPTCHA_*` keys |
| **Security headers** | CSP, HSTS, frame denial, Permissions-Policy |
| **Search & AI agents** | `robots.txt` rules for search engines, AI search/agents and link-preview bots; `sitemap.xml`; `/llms.txt`; canonical URLs; Open Graph/Twitter tags; generated OG image + PNG app icons; web manifest; schema.org JSON-LD (Organization, WebSite, WebApplication, FAQPage); private pages `noindex`; Search Console/Bing verification via env |
| **Tests** | Node test runner unit tests (real Postgres via PGlite) |
| **E2E + evidence** | Cucumber + Playwright: every actor is a separate recorded phone (CDP screencast, wall-clock aligned), fake-camera support for QR flows, RobOS evidence videos with Cucumber splash intro, step HUD and multi-phone timeline, landing-page hero GIF from the recording |
| **Deploy** | Vercel (GitHub integration) + GitHub Actions CI (`npm test`, `next build`) |

## Develop

```bash
npm install
npm run dev        # http://localhost:3000 — uses embedded PGlite, no DB setup
npm test
```

## E2E and RobOS evidence videos

```bash
npx playwright install chromium
cp .env.example .env.local           # set E2E_BYPASS_KEY to a random 24+ char string
npm run build && npm start &          # or run against production with npm run e2e:live
E2E_BYPASS_KEY=... npm run e2e        # Cucumber scenarios in tests/e2e/features
npm run evidence                      # evidence/*.mp4 + reel (splash + HUD + timeline)
scripts/make-hero-gif.sh evidence/01-*/jess.mp4 public/hero.gif "2-12"   # then HERO_IMAGE='/hero.gif' in src/lib/site.js
```

## Launch checklist

- [ ] Vercel project connected to this repo; custom domain `__DOMAIN__` + `www.__DOMAIN__`
- [ ] Neon via Vercel Marketplace (`vercel integration add neon`) → `DATABASE_URL`
- [ ] `E2E_BYPASS_KEY` (and `CRON_SECRET` if you add crons) in Vercel env
- [ ] Replace placeholder copy in `src/lib/site.js`, `/terms`, `/privacy`, `public/llms.txt`
- [ ] Add dynamic public URLs to `src/app/sitemap.js`, JSON-LD for your core entities (e.g. `Event`, `Product`)
- [ ] Verify the domain in Google Search Console + Bing Webmaster Tools, submit `/sitemap.xml`
- [ ] Decide on AI training crawlers (see comment in `src/app/robots.js`)
- [ ] Run `npm run e2e:live`, `npm run evidence`, record the hero GIF
