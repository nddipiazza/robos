# Story 04-06: Task Board UI (Kanban + List Views)

**Epic:** [Task Management](epic.md)
**Status:** Not started
**Points:** 5

## Description

Build the main Task Manager UI. Two views: Kanban board (columns = workflow stages, cards = work items, drag to advance) and List view (sortable table with filters). Show: task title, assignee avatar, priority, workflow stage, time in stage. Quick actions: assign, change priority, advance stage. Search and filter by assignee, label, epic, release.

## Acceptance Criteria

- [ ] Kanban view with drag-and-drop between stages
- [ ] List view with sortable columns and filters
- [ ] Task cards show key info at a glance
- [ ] Quick actions without opening the full task
- [ ] Keyboard navigation (j/k to move, Enter to open)
- [ ] Real-time updates when task server changes
