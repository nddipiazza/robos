# Story 10-04: Work Journal

**Epic:** [Management & Reporting](epic.md)
**Status:** Not started
**Points:** 5

## Description

Git-backed developer journal. Auto-captures: files edited, branches switched, tests run, PRs created/reviewed, CI results, deploy events. Daily entries with AI-generated summaries. Manual voice/text notes. Shareable with team via distributed store. Link entries to tasks. Search across journal history.

## Acceptance Criteria

- [ ] Data sourced from task server and CI systems (not hardcoded)
- [ ] Updates in real-time or near-real-time
- [ ] Dark theme consistent with RobOS design system
