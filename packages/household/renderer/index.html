PRODUCTION IMPORTS LOCKED

No simulated provider approval

The RobOS cloud providers app's approved-provider contract is not connected in this sandbox. No provider is claimed as verified. Production use requires that integration, encryption/key custody verification and household authorization.

Memory only

Session records and imported bytes stay in memory. The tax engine's temporary directory uses memory-backed /dev/shm.

No financial GitOps

Public code and invented test data may be versioned. Real financial files, extracted values and backups must stay in the approved private cloud.

Isolated sessions

HttpOnly session cookies and per-session request tokens. No financial localStorage, IndexedDB or request-body logging.

Only exact, allowlisted synthetic fixture bytes are accepted. This is a development safeguard, not a production vault implementation.
