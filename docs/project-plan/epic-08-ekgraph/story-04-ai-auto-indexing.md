# Story 08-04: AI Auto-Indexing

**Epic:** [EKGraph](epic.md)
**Status:** Not started
**Points:** 8

## Description

AI automatically files and organizes knowledge. When a developer mentions a service, URL, or process in conversation, voice notes, or journal entries, AI extracts structured data and creates/updates EKGraph nodes. No manual organization needed — AI determines the correct location in the graph. Human can review and correct AI's indexing.

- [ ] Schema covers the buildbarn-forms project's engineering context
- [ ] Data survives sync/restore cycle
- [ ] Other apps can query via robos-ekgraph API
