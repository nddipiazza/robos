# Story 26-03: RobOS Reviewer App (robos-reviewer)

**Epic:** [Dual-Context eLearning & Interactive Reviewer](epic.md)
**Status:** Not started
**Points:** 5

## Description

Create `packages/robos-reviewer`, a dedicated Electron application for code review. Automatically receives agent completion notifications, displaying active PRs, task tickets, diff summaries, and interactive assistance buttons.

## Acceptance Criteria

- [ ] Lists active PR reviews generated by sub-agents.
- [ ] Displays metadata: task ID, branch, CI status, diff summary.
- [ ] Features prominent action buttons: **"Teach Me How This Change Works"** and **"Show Me This Change in Action"**.
