Parses folders of classic JRPG resources that a person collected into a RobOS kgraph, and generates backgrounds, sprites and menu screens from them with Gemini.

## Source and integration

The component lives in [`packages/robos-jrpg-parser`](https://github.com/nddipiazza/robos/tree/main/packages/robos-jrpg-parser).

Its entry point is [`lib/pipeline.js`](https://github.com/nddipiazza/robos/tree/main/packages/robos-jrpg-parser/lib/pipeline.js).

See the [package README](https://github.com/nddipiazza/robos/tree/main/packages/robos-jrpg-parser/README.md) for setup and usage.

## Validation

Run `npm test` from `packages/robos-jrpg-parser`. The command is defined in the [package manifest](https://github.com/nddipiazza/robos/tree/main/packages/robos-jrpg-parser/package.json).
