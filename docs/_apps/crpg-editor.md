# RobOS cRPG Editor

RobOS cRPG Editor is the unified game development and authoring environment for `robos-crpg` (Realm of Heroes). It consolidates campaign creation, D&D 5e SRD character sheets, party inventory management, and 2.5D isometric blockmap level design into a cohesive, production-grade desktop application.

## Core Modules

1. **cRPG Campaign**: Manage high-level campaign metadata, world settings, rulesets, starting scenes, prologue synopses, quest logs, and world story flags.
2. **cRPG Character Editor**: Full hero roster management with pre-rolled archetypes (Fighter, Rogue, Wizard, Cleric, Ranger, Paladin), D&D 5e ability scores with real-time modifier calculations, combat metrics, prepared spells, and backstories.
3. **cRPG Inventory Editor**: Active 6-hero party selection, leader and tactical formation configuration (Rank, Wedge, Line, Column, Square, Scatter), party shared stash items, currency purses (GP, SP, CP), and individual hero equipment slots with live AC adjustments.
4. **cRPG Blockmap Editor**: 5-foot collision grid blockout builder, base terrain floors, background underlay artwork blending, interactive 2D canvas with object placement tools, rule/collision overrides, and compiled static PNG generation via the Python blockout engine.
