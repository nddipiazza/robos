# UI fonts

`NotoEmoji.ttf` is the monochrome variable Noto Emoji font from the Google Fonts
repository (`ofl/notoemoji/NotoEmoji[wght].ttf`). Its SIL Open Font License is
included in `NotoEmoji-LICENSE.txt` and copied into standalone notices.

Source: https://github.com/google/fonts/tree/main/ofl/notoemoji

It is an explicit fallback for Cinzel, MedievalSharp and Godot's default font.
This keeps emoji icons readable in Web builds, where system emoji fonts are
unavailable, without changing the game's text typography.
