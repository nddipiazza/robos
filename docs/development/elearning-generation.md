# E-learning generation

Task Planner turns a saved feature plan into lessons using the same generation service and teaching policy as the shared player's AI editor. Plan headings are not converted directly into slides.

Lessons introduce the purpose and unfamiliar concepts, walk through an example, explain the intended workflow and its delivery checks, and test understanding after teaching it. Technical findings become relevant behavior to implement or verify. Required reviewers and dependencies remain part of the explanation.

Source-access checks, inspection logs, PR inventories, timestamps, local clone paths and agent execution reports belong in provenance, not lessons. The original plan, issue and plan hash remain in KGraph metadata. Necessary unresolved product decisions are explained where they affect the workflow, without repeating audit disclaimers.

Generation failures leave the saved course unchanged. Audit-shaped sections and malformed quizzes are rejected. Courses generated by the current teaching policy are reused for the same plan; explicitly creating a course from an older mechanically split version regenerates it. Concurrent creation requests for the same graph/plan share one generation, and concurrent edits to that course prevent overwriting it.
