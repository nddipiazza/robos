# Story 25-05: Desktop Agents Viewer App (desktop-agents)

**Epic:** [RobOS Desktop Agents](epic.md)
**Status:** Not started
**Points:** 5

## Description

Build `packages/desktop-agents`, an Electron viewer application for the host desktop that allows developers to monitor, switch between, and interactively control live agent desktop streams.

## Acceptance Criteria

- [ ] Displays grid and tabbed views of all active sub-agent sessions.
- [ ] Renders live 60fps desktop video stream with audio/input toggle.
- [ ] Allows host developer to take manual keyboard/mouse control when requested.
