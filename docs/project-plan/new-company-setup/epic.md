**Status:** In Progress
**Priority:** High
**Dependencies:** Desktop Foundation, Security & Auth, Group Manager, AI Agent Integration

Includes company identity and root admin setup, foundational team topologies, greenfield VCS organization initialization (GitHub Org / Gitea), central AI model provider distribution & shared MCP registry, baseline security policies, and starter C4 architecture.
