Agents shouldn't open noisy pull requests before a developer has inspected the work. We restructured the delivery workflow across Task Implementer, Dev Central v2, and PR Review Theater (packages/pr-review) so agents push a feature branch first and hand off to a local review stage:

  • Changes, Evidence & Steerable Walkthroughs: Developers inspect syntax-highlighted diffs, before/after screenshot evidence, and editable multi-checkpoint walkthroughs—and can send live steering messages in the side-pane chat to refine code, evidence, or demo steps in place.
  • Factual PR Descriptions & Team Handoff: When ready, developers create a draft PR with Markdown descriptions grounded in real walkthrough screenshots, monitor live GitHub Actions and Buildkite logs, trigger guided local CI repair on failed checks, and undraft with prefilled reviewers and Slack mentions.
  • Desktop Polish: Shipped the RobOS GNOME Desktop App Installer (packages/gnome-desktop-installer) with background worker-thread shortcut repair, plus a built-in skill browser in <robos-ai-textarea>.
