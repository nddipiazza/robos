# Story 01-03: Package Structure & Public API

**Epic:** [buildbarn-forms-proto Package](epic.md)
**Status:** Complete
**Points:** 3

## Description

Define the npm package structure, `package.json`, and public exports for `@hermetiq/buildbarn-forms-proto`. The package must be importable as ES modules, published to GitHub Packages (npm registry), and expose the generated types in a way that consumers can selectively import only what they need to avoid bundle bloat.

## Acceptance Criteria

- [ ] `package.json` sets `"type": "module"` for ESM output
- [ ] `"main"` and `"types"` point to compiled `dist/index.js` and `dist/index.d.ts`
- [ ] `"files"` field includes only `dist/` (no source, no scripts)
- [ ] `publishConfig.registry` points to `https://npm.pkg.github.com`
- [ ] `dist/proto-comments.json` is accessible to consumers at runtime
- [ ] README documents how to import types and how to access the comment map
- [ ] `npm run build` produces a valid, importable package

## Public API Shape

```typescript
// Direct proto type imports (recommended to avoid bundle bloat)
import { ApplicationConfiguration } from
  '@hermetiq/buildbarn-forms-proto/dist/github.com/buildbarn/bb-storage/pkg/proto/configuration/bb_storage/bb_storage.js';

// Comment map (for tooltip system)
import protoComments from
  '@hermetiq/buildbarn-forms-proto/dist/proto-comments.json' assert { type: 'json' };
```
