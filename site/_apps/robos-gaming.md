RobOS Shared Gaming Library — Core Gaming Ontology, Dice Subsystems, Grid Mathematics, and Cartridge Engine


## Shared game building blocks

`index.js` exports dice helpers (`UniversalDiceEngine` and `dice`), `BoardGrid`, HeroQuest board definitions, map configurations, `GameCartridgeBundler` and the shared gaming ontology helpers.

The implementation files live in `lib/`. The [Tabletop RPG](/robos-tabletop/), [Blockmap Creator](/tabletop-blockmap-creator/) and [Quest Map Editor](/tabletop-quest-editor/) build on these shared definitions.
