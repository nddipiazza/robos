# Epic 28: Unified Setup Assistant & AI Project Provisioner

**Status:** Not started
**Priority:** High
**Dependencies:** Epic 13 (Security & Auth), Epic 06 (AI Agent Integration), Epic 05 (Workspace Management)

A unified first-boot setup assistant (`packages/robos-onboarding`) that consolidates GPG security keys, Git/VCS authorization, and AI agent credentials upfront into a single flow, while suppressing piecemeal popups and toasts until completion. Upon completion, a RobOS AI agent uses automated workspace skills to configure developer projects end-to-end.
