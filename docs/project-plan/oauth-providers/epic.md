# OAuth Provider Integration

**Status:** Not started
**Priority:** Low
**Dependencies:** Security & Auth

Generic OAuth provider management for all RobOS integrations. Covers OAuth PKCE flows, token storage in the pass store, auto-refresh, and a provider configuration UI. This is post-MVP — the MVP uses API tokens and `gh auth` for authentication.
