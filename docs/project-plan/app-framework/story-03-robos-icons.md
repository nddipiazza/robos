# Story 02-03: robos-icons SVG Registry

**Epic:** [App Framework](epic.md)
**Status:** Done
**Points:** 3

## Description

Create packages/robos-icons/ with BUILTIN_APPS array containing SVG icons for all planned RobOS apps. Icons are 48x48, Lucide style, using the RobOS color palette (cyan, teal, green, blue, purple, pink, orange, yellow, red, gray).

## Acceptance Criteria

- [ ] Icons for all planned apps registered
- [ ] getIcon(appId) and getAllIcons() exported
- [ ] All SVGs valid and render at 48x48 and 16x16
