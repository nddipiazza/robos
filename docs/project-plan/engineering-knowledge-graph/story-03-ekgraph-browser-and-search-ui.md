# Story 08-03: EKGraph Browser and Search UI

**Epic:** [EKGraph](epic.md)
**Status:** Not started
**Points:** 5

## Description

Electron app to browse and search the knowledge graph. Tree view of the node hierarchy. Search with AI-powered natural language queries ('where are the staging logs for bb-storage?'). Node detail view with all fields, linked nodes, and version history. Edit nodes inline with validation against schema.

## Acceptance Criteria

- [ ] Schema covers the buildbarn-forms project's engineering context
- [ ] Data survives sync/restore cycle
- [ ] Other apps can query via robos-ekgraph API
