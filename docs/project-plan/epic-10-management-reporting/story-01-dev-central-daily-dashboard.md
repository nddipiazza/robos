# Story 10-01: Dev Central Daily Dashboard

**Epic:** [Management & Reporting](epic.md)
**Status:** Not started
**Points:** 5

## Description

The developer's home screen. Shows: active tasks with workflow stage, open PRs with CI status, sprint board summary from task server, AI-generated standup summary (what you did yesterday, plan for today), blocker radar (stuck tasks, failed CI, pending reviews), calendar integration, quick links to active workspaces.

## Acceptance Criteria

- [ ] Data sourced from task server and CI systems (not hardcoded)
- [ ] Updates in real-time or near-real-time
- [ ] Dark theme consistent with RobOS design system
