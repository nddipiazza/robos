`packages/pulse-metrics-cli` is the reference command-line utility generated by the [New App Wizard](/new-app-wizard/) (`node-cli` archetype). It demonstrates how a zero-dependency Node.js CLI is registered in the RobOS Knowledge Graph (`.robos/kgraphs/applications/package.jsonld`) alongside a Backstage `catalog-info.yaml`, `Dockerfile`, and `dev-setup.sh`.

## CLI commands (`bin/cli.js`)

```bash
cd packages/pulse-metrics-cli
node bin/cli.js --help
node bin/cli.js status
node bin/cli.js report
npm test
```

- **`status`**: Reports current service probe status and simulated endpoint latency metrics in terminal output.
- **`report`**: Emits a structured uptime and diagnostics summary suitable for piping into scripts or CI logs.

See [Projects](/projects/) and [New App Wizard](/new-app-wizard/) for scaffolding new CLI tools from this archetype. Source: [`packages/pulse-metrics-cli`](https://github.com/nddipiazza/robos/tree/main/packages/pulse-metrics-cli).
