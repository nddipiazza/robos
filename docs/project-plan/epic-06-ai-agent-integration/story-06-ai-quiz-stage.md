**Epic:** [AI Agent Integration](epic.md)

## Description

After human review, agent generates 3-5 quiz questions to ensure the developer understands the change. Questions cover: what the change does, edge cases, potential risks. Developer answers in the app. This is optional (can be disabled in workflow config) but recommended — ensures developers can speak to changes in code review.
