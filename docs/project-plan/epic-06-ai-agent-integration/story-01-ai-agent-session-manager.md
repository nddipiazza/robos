# Story 06-01: AI Agent Session Manager

**Epic:** [AI Agent Integration](epic.md)
**Status:** Not started
**Points:** 8

## Description

Electron app to start/stop/monitor AI agent sessions. Assign agents to tasks — when assigned, the agent picks up the task and drives it through the workflow stages. Show: active sessions, token usage, conversation history, cost. Support multiple simultaneous agent sessions. Agent sessions persist across app restarts.

## Acceptance Criteria

- [ ] Tested end-to-end with buildbarn-forms example task
- [ ] Agent actions visible in real-time in the UI
- [ ] Task workflow stage advances correctly
