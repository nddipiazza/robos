DocuVault Desktop (`packages/docu-vault-desktop`) is the reference Electron desktop starter generated by the [New App Wizard]({{ '/new-app-wizard.html' | relative_url }}) (`electron-desktop` archetype). It provides a minimal Electron shell (`main.js`, `preload.js`, `renderer/index.html`), a FreeDesktop `.desktop` launcher, a Backstage `catalog-info.yaml`, and a knowledge-graph node in `.robos/kgraphs/applications/package.jsonld`.

See [Projects]({{ '/projects.html' | relative_url }}) for how the App Wizard archetypes are structured across desktop, web, CLI, and microservice starters.

## Running it

```bash
cd packages/docu-vault-desktop
npm install
npm start
```
