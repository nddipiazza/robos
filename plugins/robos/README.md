# RobOS Developer Skills Plugin

Official SDLC toolchain, VM lifecycle management, Electron app scaffolding, DOM snapshot inspection, and testing skills for RobOS.

## Overview

This plugin bundles 22 specialized skills for AI coding agents to interact with and develop within the RobOS ecosystem.

## Supported Agents
- Claude Code
- OpenAI Codex
- Google Antigravity
- GitHub Copilot
- Gemini CLI
- Cursor
