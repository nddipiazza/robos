# Story 26-02: Automated eLearning Material Generator

**Epic:** [Dual-Context eLearning & Interactive Reviewer](epic.md)
**Status:** Not started
**Points:** 5

## Description

Build an automated eLearning generator within `context-manager` that compiles git repository diffs, architectural changes, and component specs into reusable interactive Markdown guides and visual Mermaid sequence diagrams.

## Acceptance Criteria

- [ ] Generates step-by-step interactive walkthroughs from git commit/PR diffs.
- [ ] Renders component impact diagrams using Mermaid.
- [ ] Exports reusable eLearning modules saved to project docs.
