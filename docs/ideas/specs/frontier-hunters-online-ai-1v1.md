# Frontier Hunters online AI 1v1

From **Online 1v1**, choose **Frontier Hunters**, pick a faction or **Random** independently for each side, then watch two RobOS commanders play the match on `robos-game-server`. The battlefield is the existing 256×256 Frontier Hunters map. The ruleset is the current StarCraft II Legacy of the Void 1v1 balance in Blizzard's 5.0.17 notes. Use the original Starfall Command names and assets in the game. [Blizzard's 5.0.17 live patch notes](https://news.blizzard.com/en-us/article/24309308/starcraft-ii-5-0-17-patch-notes)
