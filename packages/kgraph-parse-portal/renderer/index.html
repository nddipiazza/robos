RobOS KGraph Parse Portal Architecture

          

            
Overview

            
The RobOS Kgraph Parse Portal is a heavy-scale connectors webapp and headless ingestion portal designed to map any Linux filesystem resource or web document into the validated Dual-State Knowledge Graph.

            
            
Core Capabilities

            
    
              
  • Linux Filesystem Ingestion: Every file on a Linux OS (executables, shared libraries, systemd services, Unix domain sockets, named pipes, device nodes, source code) finds representation in the KGraph with cryptographically verifiable robos:evidence (SHA-256 hash, relative path, working-tree revision).
    • 
              
  • MIME Disambiguation: Contextual disambiguation of ambiguous MIME types (e.g. application/json into Node.js manifests vs TypeScript configs vs OpenAPI specs vs JSON-LD graphs; YAML into Helm charts vs Kubernetes manifests vs CI/CD pipelines).
    • 
              
  • Apache Tika 4.0 Streaming gRPC: Native integration with tika-grpc for document extraction, AST symbol identification, and polyglot text extraction with resilient offline fallbacks.
    • 
              
  • Hermetiq Buildbarn Helm RBE: Orchestrates remote build execution clusters via oci://ghcr.io/hermetiq/buildbarn for high-throughput Bazel/Buck2 builds and heavy parse worker distribution.
    • 
              
  • Luxir Search Index: Bridges parsed KGraph nodes to the C++ Luxir search index for sub-millisecond full-text and faceted search queries.
    •
