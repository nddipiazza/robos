# New App Development Wizard

**Status:** In Progress
**Priority:** High
**Dependencies:** App Framework, Contract Studio, Topology Manager, Workspace Management

A guided multi-step GUI Wizard (packages/app-wizard) for creating brand-new applications across all 6 multi-app archetypes (Desktop App, Microservice, Console CLI, Mobile App, Data Pipeline, Library / SDK), contract definition, polyglot scaffolding generation (dev-setup.sh, .devcontainer/, Dockerfile, tests, catalog-info.yaml), and Knowledge Graph registration.
