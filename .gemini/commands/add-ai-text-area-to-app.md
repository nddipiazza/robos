# Add AI Textarea to a RobOS App

Add the standard `<robos-ai-textarea>` widget to any RobOS Electron app.

## When to use this command

Use whenever you need to add an AI-powered text input to a RobOS app. Never create a plain `<textarea>` or `<input type="text">` for AI prompts.

Follow the instructions in `plugins/robos/skills/add-ai-text-area-to-app/SKILL.md`.
