**RobOS VPN Servers** (`packages/vpn-servers`) manages OpenVPN providers (with **IPVanish** built in), user accounts (`~/.config/robos/ovpn-accounts.json` + encrypted passwords in `pass`), and `.ovpn` server profiles across RobOS.
