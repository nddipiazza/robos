Connecting external storage and media libraries across desktop apps required too much manual form entry. We overhauled Cloud Storage & Data Sources (packages/data-sources) around a guided 3-step connection wizard with real Google OAuth 2.0 browser sign-in, live Google Drive API folder mounting, top-right authentication status toasts, and native FTP/SFTP storage drivers alongside PostgreSQL schema inspection.

  • Managed Library Folders: RobOS Audio Player (packages/audio-player) mounts local directories, FTP servers, and SFTP shares as managed libraries with one-click sync, rename, and removal. Folder scanning runs on a background worker thread so large music libraries never stall the UI.
  • Playlists, Synced Lyrics & Amber Library View: Added a sortable, list-based library view with a warm amber palette, synced lyric display, M3U playlist import/export, and Howler.js + H5AudioPlayer playback.
  • Local Cast & Home Speaker Intercom: Built zero-cloud Google Home / Cast discovery and streaming directly from the Now Playing deck, plus the companion RobOS Home Speaker app (packages/home-speaker) for push-to-talk intercom broadcasts, neural TTS announcements, and scheduled chimes.
