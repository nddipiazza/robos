**Epic:** [Release & Packaging](epic.md)

## Description

Electron app that runs on first login (replaces GNOME initial-setup). Steps: welcome screen, connect task servers (GitHub/Jira), configure AI (API keys for Claude/Copilot), set up Git identity (name/email, SSH key generation), clone initial repos, choose preferred IDE. All settings saved to RobOS config.
