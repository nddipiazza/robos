# Epic 21: GitHub Pages Documentation Site

**Status:** Not started
**Priority:** High
**Dependencies:** None

Publish a polished, navigable documentation site for RobOS on GitHub Pages. The site showcases the Model Problem (building buildbarn-forms with RobOS), the full app suite with icons, architecture, user personas, and workflow diagrams. Uses Jekyll with the just-the-docs theme for clean navigation and dark-mode support.

## Why This Is Important

RobOS has extensive internal docs (model problem, workflow examples, app plans, 20 epics with 145+ stories) but none of it is published or navigable. A documentation site makes the project accessible to anyone evaluating RobOS and demonstrates the end-to-end vision using the buildbarn-forms Model Problem.
