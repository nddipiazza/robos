# Story 09-04: Microphone Indicator and Push-to-Talk

**Epic:** [Voice & Input](epic.md)
**Status:** Completed
**Points:** 3

## Description

Global push-to-talk hotkey (`Super+V`) toggles microphone listening from anywhere on the desktop. Visual feedback includes an animated pulse status pill, real-time Web Audio API `AnalyserNode` waveform volume bars, and live streaming indicator (`● LIVE STREAMING DICTATION`) with auto-scrolling recognized speech text.

## Acceptance Criteria

- [x] Works offline (no network required)
- [x] Global push-to-talk shortcut (`Super+V`)
- [x] Real-time live audio waveform visualizer and streaming indicator
