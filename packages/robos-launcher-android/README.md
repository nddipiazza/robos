# RobOS Home for Android

The home screen for the RobOS phone image in `infra/android`. It shows the time, the date, every installed `com.robos.*` app, and Settings, which a phone needs to join Wi-Fi. Other installed apps stay hidden.

```bash
./gradlew assembleDebug
```

To try it on any Android 11 or later phone, install the APK, then choose RobOS Home as the home app in Settings.
