# Story 07-06: Stage Demo Viewer

**Epic:** [Code Review & CI/CD](epic.md)
**Status:** Not started
**Points:** 5

## Description

When changes deploy to staging, AI generates a demo walkthrough for the Product Owner: what changed, screenshots/recordings of the UI changes, how to verify. PO reviews the demo and approves or files bugs. Linked to the Release and Epic for tracking. Reduces PO review time from hours to minutes.

## Acceptance Criteria

- [ ] Tested with buildbarn-forms GitHub repo
- [ ] Integrates with Task Manager workflow stages
- [ ] Real-time updates (no manual refresh)
