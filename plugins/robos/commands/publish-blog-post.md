# Publish Engineering Blog Post

Add a new newest-first entry to the RobOS Engineering Blog (`site/blog/index.md`) with jump navigation, E2E screenshots/videos, reproducible CLI commands, docs links, and commit hashes.

## Usage
Follow the steps in `plugins/robos/skills/publish-blog-post/SKILL.md` to add the jump link and `<article class="blog-entry">` block at the top of `site/blog/index.md`.
